# Evolution of the Portfolio Optimization Project

This document records how the project developed from classical mean-variance theory into a topology-aware and distribution-aware research pipeline.

## PO1 — Classical portfolio geometry

The project began with the efficient frontier and mean-variance spanning.

For portfolio weights $\mathbf w$, expected return and variance are

$$
\mathbb E[R_p]=\mathbf w^\top\boldsymbol\mu,
\qquad
\operatorname{Var}(R_p)=\mathbf w^\top\Sigma\mathbf w.
$$

Mean-variance spanning asks whether adding a candidate set of assets improves the frontier generated by a baseline set. This established the final portfolio-construction goal, but it did not solve the estimation-noise problem.

## PO2 — Wasserstein geometry

The next step was to represent each asset by its entire empirical return distribution rather than only its mean and variance.

Wasserstein distance provides a metric between probability distributions. It can distinguish two assets with similar first and second moments but different skewness, tails, or multimodality.

This suggested a distribution-aware stock-selection layer before optimization.

## PO3 — K-means and MMD

Ordinary K-means was studied as a baseline clustering method. Its Euclidean centroid structure is not ideal when the objects being clustered are distributions.

Maximum mean discrepancy was then added as a kernel-based difference between distributions. The project considered an MMD stock-selection hypothesis: assets that are sufficiently distinct in distributional feature space may contribute less-redundant information to a portfolio universe.

## PO4 — W-K-means direction

Wasserstein K-means replaces Euclidean distances with Wasserstein distances and represents cluster centers by Wasserstein barycenters.

The current implementation uses K-medoids instead. This is a deliberate first-stage approximation:

- it accepts an arbitrary precomputed distance matrix;
- each center is an observed asset rather than an estimated barycenter;
- it combines Wasserstein and MMD geometry directly;
- it is simpler to audit and reproduce.

Wasserstein barycenter clustering remains a future comparison.

## PO5 — Persistent homology for structural noise and regimes

Persistent homology was introduced from topological analysis of financial time series.

The key conceptual correction is:

> Persistent homology does not remove individual daily observations. It removes short-lived topological features from persistence diagrams.

Rolling multivariate market-state clouds are converted into Vietoris-Rips filtrations. First-homology loops that die quickly are treated as topological noise; longer-lived loops form a structural regime signal.

This branch complements distributional clustering:

| Branch | Object | Main purpose |
|---|---|---|
| Persistent homology | Rolling market-state point cloud | Detect structural regime change through time |
| Wasserstein/MMD | Asset return distributions | Compare and cluster the asset universe |

## PO7 — Causal evaluation design

The notebook uses training slices of the form:

```python
returns.iloc[t - lookback:t]
```

Because the right endpoint is excluded, the return at $t$ is not used to choose the weights applied beginning at $t$.

At each rebalance:

1. the model forms a trailing training sample;
2. recomputes distribution distances;
3. reclusters and selects assets;
4. recomputes the topological regime score;
5. estimates moments;
6. solves for weights;
7. holds the weights out of sample;
8. deducts transaction costs.

## PO8 — Current research state

The software path is implemented, but scientific conclusions remain pending. The repository does not yet contain a fixed, fully reported empirical experiment with:

- a frozen asset universe and study period;
- all generated output CSVs;
- component ablations;
- nested hyperparameter tuning;
- confidence intervals;
- multiple transaction-cost assumptions;
- sensitivity to rebalance frequency and training-window length.

These missing items are validation work, not hidden positive results.

## Planned extensions

### Formal mean-variance spanning

Replace or supplement the descriptive frontier comparison with a formal statistical spanning test.

### Wasserstein barycenters

Compare K-medoids with true Wasserstein barycenter clustering.

### Distributional persistent homology

Construct a Vietoris-Rips complex whose vertices are asset distributions and whose metric is Wasserstein distance:

$$
\operatorname{VR}_\epsilon\left(\{\mu_1,\ldots,\mu_n\},W_p\right).
$$

This is mathematically valid because a Vietoris-Rips complex requires a metric space, but it should be tested as a separate extension so its contribution can be identified.

### Nested model selection

Tune all hyperparameters only inside each training period. This prevents the full backtest from indirectly influencing threshold, cluster, or optimizer choices.
