# PO01 — Integrated Topology-Aware Portfolio Notebook

Notebook: [`research/topology_aware_portfolio_optimization.ipynb`](research/topology_aware_portfolio_optimization.ipynb)

## Purpose

PO01 is the first complete executable version of the project. It connects topological regime analysis, distributional asset clustering, mean-variance diagnostics, optimization, and causal backtesting in one notebook.

## Cell guide

| Cells | Section | Purpose |
|---|---|---|
| 0–1 | Objective and language choice | Defines the research question and explains why Python is used |
| 2–3 | Installation | Installs `yfinance` and `ripser` |
| 4–5 | Imports | Loads numerical, statistical, topology, plotting, and optimization libraries |
| 6–7 | Configuration | Defines assets, windows, thresholds, optimizer parameters, and output location |
| 8–10 | Data | Downloads adjusted prices, computes log returns, and plots normalized prices |
| 11–13 | Persistent homology | Builds rolling market-state clouds, filters short loops, and creates a regime score |
| 14–17 | Distributional clustering | Computes Wasserstein/MMD distances, performs K-medoids, and selects representatives |
| 18–19 | Spanning diagnostic | Compares long-only efficient frontiers |
| 20–21 | Optimizer | Solves the regime-aware constrained allocation problem |
| 22–25 | Walk-forward engine | Runs full-model and benchmark strategies causally |
| 26–30 | Evaluation | Reports metrics, wealth, drawdown, topology, and allocations |
| 31–32 | Export | Saves reproducible CSV outputs |
| 33 | Interpretation | States hypotheses and next experiments |

## Recommended first run

Keep:

```python
fast_mode: bool = True
```

Run all cells from top to bottom. Confirm that:

- price data load;
- no required ticker is dropped;
- the distance matrices are finite;
- at least one representative is selected per cluster;
- optimization succeeds;
- each strategy returns a nonempty time series;
- the output CSV files are created.

Only then change `fast_mode` to `False`.

## Data fallback

If Yahoo Finance is unavailable, set:

```python
local_price_csv = "path/to/adjusted_prices.csv"
```

The CSV must have:

- a date index in the first column;
- one adjusted-price column per ticker;
- ascending dates;
- no duplicate dates.

## Main configuration parameters

| Parameter | Default | Meaning |
|---|---:|---|
| `train_window` | 504 | Trading days used to estimate clustering and portfolio moments |
| `rebalance_every` | 21 | Approximate monthly rebalance |
| `tda_window` | 60 | Trading days in each market-state point cloud |
| `n_clusters` | 4 | Number of asset clusters |
| `wasserstein_weight` | 0.65 | Weight of Wasserstein geometry in combined distance |
| `mmd_weight` | 0.35 | Weight of MMD geometry |
| `base_risk_aversion` | 8.0 | Base covariance-risk penalty |
| `transaction_cost_bps` | 10.0 | Configured cost per measured turnover unit |
| `fast_mode` | `True` | Shorter initial experiment |

## Interpretation rule

Do not read one notebook run as a validated trading strategy. PO01 is a research apparatus for comparing clearly specified hypotheses under causal evaluation.
